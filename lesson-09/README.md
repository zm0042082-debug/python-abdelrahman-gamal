- : يوجد عدة انواع للبيانات 

1- ( string 'str' = سلسلة نصية)

أهم خصائص الـ String
التنصيص: يتم إنشاؤه وضع النص بين علامات تنصيص مفردة (' ') أو مزدوجه* 
(" ").
الشمولية: يمكن أن يحتوي على حروف عربية، إنجليزية، أرقام، مسافات، وحتى رموز تعبيرية 
(Emojis).
الأرقام كنصوص: إذا كتبت رقمًا داخل علامات تنصيص مثل "123"، يعامله البرامج كـ نص وليس كقيمة* حسابية (أي لا يمكنك إجراء عمليات جمع أو ضرب مباشرة عليه دون تحويله).

EX:  x="Zeyad" صح
     print(x)
     = Zeyad صح 
*لازم علامتين التنصيص*
     x=zeyad خطاء



2- ( integer 'int' = العدد بدون ارقام عشريه)

أهم خصائص الـ Integer
بدون كسور: يشمل الأعداد الموجبة، والسالبة، والصفر (مثل: 5, -20, 0) *
 إجراء العمليات الحسابية: يمكنك تطبيق كافة العمليات الرياضية المباشرة عليه*
 .(جمع، طرح، ضرب، قسمة)
.الدقة: لا يفقد الدقة لأن الحسابات تتم على أعداد كاملة*

EX:1 x = 10   &   "10" 
     print(x)
     = 10   صح
     
EX:2 x =10*10
     print(x)
     = 100  صح
 *مينفعش  اجمع جزء عليه علامتين تنصيص وجزء لا*
     x= 10 +"10"  خطاء

3- (float = عدد يحتوي ع ارقام عشرية )

أهم خصائص الـ Float
يحتوي على كسور: يُستخدم عند الحاجة إلى دقة في القياسات والأرقام غير الصحيحة* 
(مثل: 3.14, -0.5, 99.99).
العمليات الحسابية: تُجرى عليه جميع العمليات الرياضية مثل الأعداد الصحيحة*
التحويل: إذا أضفت نقطة عشرية لأي رقم صحيح (مثلاً 5.0) يتحول نوعه فوراً إلى* 
Float.

EX:  x= 10.5
     print(x)
     = 10.5 صح


4- (Boolean = قيمة منطيقية واحده)

أهم خصائص الـ Boolean
قيمتان فقط لا ثالث لهما*
تتكون من قيمتين محددتين تماماً:
True (صحيح / 1)
False (خطأ / 0)

*أساس اتخاذ القرارات (Control Flow)
هي المحرك الأساسي للشروط في البرمجة (if / else). من خلالها يقرر البرنامج أي طريق يسلك بناءً على تحقق الشرط من عدمه.

EX:1  x= False  صح 
      print(x)

      x= "False" خطاء             (str)  لانها كدا اصبحت 
      x= ture   خطاء

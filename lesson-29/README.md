# اسم الدرس

انشاء لعبة احسب عمرك بالايام

## ماذا تعلمت؟

- كيف انشاء لعبة لحساب عمرك بالايام
EX:

def  calcdays(age):
     return ("your age in days is: ")+ str (age*365) + ("days")
print(calcdays(23))
=your age in days is: 8395 days

- كيف انشاء لعبة لحساب عمرك بالساعات
EX:

def  calchours(age):
     return "your age in hours is: " + str (age*365 *24) + " hours"
print(calchours(23))
=your age in hours is: 201480 hours

- (input)كيف انشاء لعبة لحساب عمرك لما ادخل مدخل 
EX1:

def  calchours(age):
     return "your age in hours is: " + str (age*365 *24) + " hours"
print(calchours(input ("enter your age: ")))

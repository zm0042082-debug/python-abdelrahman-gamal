## ماذا تعلمت؟

- 1- اذا كانت الحروف التي ستطبع سمول ومحتاج اخليها كابتل
بكتب ع Upper() بتحول من الصمول للكابتل  
EX:  name = "Zeyad"
     print(name.Upper())
     =ZEYAD

- 2- اذا كانت الحروف التي ستطبع كابتل ومحتاج اخليها صمول
بكتب ع lower()  بتحول من الكابتل للصمول
EX:  name = "ZEYAD"
     print(name.lower())
     =zeyad

- 3- بسأل لو الحروف الي هطبعها كابتل 
بكتب ع isupper()لو هي فعلا كابتل هتقول صح ولو لا هتقول خطاء
EX:  name = "ZEYAD"
     print(name.isupper())
     =true
EX:  name = "zeyad"
     print(name.isupper())
     =false

     
- 4- بسأل لو الحروف الي هطبعها صمول 
بكتب ع islower()لو هي فعلا صمول هتقول صح ولو لا هتقول خطاء
EX:  name = "zeyad"
     print(name.islower())
     =true
EX:  name = "ZEYAD"
     print(name.islower())
     =false

- 5-لو عايز اول حرف ف اول كلمة ف الجمله فقط كابتل 
بكتب capitalize
EX:  name = "zeyad mahmoud"
     print(name.capitalize())
     =Zeyad mahmoud

- 6-لو عايز اول حرف ف كل كلمة ف الجمله كابتل 
بكتب title
EX:  name = "zeyad mahmoud"
     print(name.title())
     =Zeyad Mahmoud
